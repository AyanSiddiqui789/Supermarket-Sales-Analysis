# 🛒 Supermarket Sales Analysis

## 📌 Project Overview

This project analyzes supermarket sales data to understand sales performance, customer behavior, payment methods, product performance, and branch-wise sales.

The project uses Python, MySQL, SQL, and Power BI to perform data analysis and create an interactive dashboard.

---

## 🛠️ Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- MySQL
- SQL
- Power BI
- GitHub

---

## 📊 Project Workflow

1. Data collection and preparation
2. Data analysis using Python
3. Data storage and analysis using MySQL
4. SQL-based business analysis
5. Dashboard creation using Power BI
6. Project documentation and publishing on GitHub

---

## 🔍 Analysis Performed

The project includes analysis of:

- Total Sales
- Total Transactions
- Average Sales
- Average Customer Rating
- Sales by City
- Sales by Branch
- Sales by Product Line
- Sales by Gender
- Sales by Payment Method
- Daily Sales Trends
- Customer Type Analysis

---

## 📈 Power BI Dashboard

The Power BI dashboard provides a visual overview of supermarket sales performance.

### Key Dashboard Metrics

- Total Transactions: 500
- Total Sales: Approximately 1.90M
- Average Sales: Approximately 3.80K
- Average Rating: Approximately 3.98

The dashboard also includes charts for city, branch, product, gender, payment method, and daily sales trends.
